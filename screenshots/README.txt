This is the default folder screenshot.php watches for the newest image.

You have two options:
  1. Point screenshot.php's $screenshotFolder setting at your simulator's
     real screenshot folder instead of this one, or
  2. Have your simulator (or a copy step) save screenshots directly into
     this folder.

Either way, this folder itself can be emptied out - it's just a
placeholder so the project has somewhere to point at out of the box.
